# Dashboard Agents Landing

Static landing page for selling Dashboard Agents Early Access.

## Structure

- `index.html`: main sales page
- `success.html`: post-payment confirmation page
- `privacy.html`: privacy policy
- `terms.html`: terms and early access conditions
- `styles.css`: global design system and responsive layout
- `robots.txt`: crawler instructions
- `sitemap.xml`: sitemap placeholder
- `assets/`: static assets

## Stripe

Replace every `https://buy.stripe.com/REPLACE_WITH_PAYMENT_LINK` placeholder with the real Stripe Payment Link.

## Deployment

This is a static site. It can be deployed on Cloudflare Pages, Netlify, Vercel, GitHub Pages, or any static host.
